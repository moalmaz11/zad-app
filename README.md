## ✨ المميزات الرئيسية

* 🕋 **مواقيت صلاة متفاعلة:** حسابات دقيقة للأوقات مع واجهة تتفاعل بصرياً مع أوقات اليوم وعداد تنازلي للصلاة القادمة.
* 📖 **أذكار بانتقال ذكي:** تجربة قراءة مريحة مع عداد تكرار تلقائي ينقلك للذكر التالي فور الاكتمال لتعزيز الخشوع.
* 📿 **مسبحة حسية ذكية:** زر رقمي واسع مدعوم باهتزازات خفيفة (*Haptic Feedback*) مع حفظ مستمر للتقدم.
* 📊 **تتبع الالتزام وبناء العادات:** نظام إحصائيات محلي متكامل لمتابعة استمرارية صلواتك وأذكارك اليومية.

## 🛠️ الخصائص التقنية

* **100% يعمل بدون إنترنت (Offline):** يتم تخزين ومعالجة جميع البيانات محلياً.
* **خالٍ تماماً من الإعلانات:** تجربة نقية بدون إعلانات منبثقة أو بنرات مزعجة.
* **أداء فائق وخفة في الحجم:** حجم التطبيق لا يتعدى 16 ميجابايت مع استهلاك شبه منعدم للبطارية.
